# Using Parks Computing

The Parks Computing menu opens the home page, site information, and site settings. Go holds navigation. Applets opens tools, while Window manages tools and articles that are already open. Selecting an open applet retains its work. The Terminal Session menu can create another terminal.

View switches between the Windowed workspace and Classic pages, and changes the theme. Commands contributed by the active applet appear beneath its name in Go, View, or Help. The separate applet menu holds that applet's file, editing, and working commands.

The taskbar spans the bottom of the Windowed workspace. Article buttons carry the Parks Computing logo, and tool buttons carry an applet icon. The sidebar button at its left hides or shows the list. On a phone, showing the sidebar minimizes the visible windows; pressing the button again brings those windows back. The button follows window actions automatically and is disabled when no windows are open on a phone.

The thick divider stays visible when the sidebar is collapsed. Drag it inward to reopen the list, or resize the list by dragging it on a wide screen. With the divider focused, Enter toggles the sidebar and the arrow keys resize it. Home collapses it, End expands it, and a double-click restores its default width on a wide screen.

Use Tab to reach the menu bar. Left and Right move between titles, and Enter or Down opens a menu. Arrow keys move through its commands. Escape closes it and returns focus to the title; Tab leaves the menu. Clicking or tapping an open title or its menu glyph closes it. On a small screen, choose a named menu and use Back to return to its parent.

Applet shortcuts apply while focus is inside that applet. Browser and text-field shortcuts remain available. The buttons on each applet provide direct access to frequent operations.

The Window menu lists open windows and supplies controls supported by the active window. Windows that size to their content do not offer maximize, snap, or dock. Close window closes that instance; an editor's Close document closes only its current document and checks for unsaved changes.

Open as a page gives an applet or article its own browser page. Copy link to this applet shares the state supported by that applet. Use the browser address to bookmark the workspace. Opening a menu does not change the address or add a browser history entry.
